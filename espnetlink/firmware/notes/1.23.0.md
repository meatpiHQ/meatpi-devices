# ESPNetLink 1.23.0

## Before you update
- Units already on this partition layout (v1.23 (two 5 MB OTA slots, settings, storage, coredump)) update in place.
- Units coming from firmware 1.20.0 (v1.20 (one factory app slot, no OTA)) cannot update over the air: flash this release over USB with the serial flash set.

## New features
- The dongle is updated by a connected WiCAN PRO (firmware 6.1 or newer): the WiCAN downloads the image, checks it and sends it over USB or WiFi; the dongle restarts once.
- The version is `1.23.0` and the image name no longer changes with the build; a WiCAN PRO refuses an image that is not an ESPNetLink image.
- An updated image is confirmed once the dongle is on the mobile network or after two minutes of running; on a dongle flashed over USB with this release, a crash before that confirmation boots the previous firmware again.
- Assisted GPS and the WiFi access point ship off and are switched on by the WiCAN PRO when it needs them.

## Bug fixes
- A firmware upload that stalls is given up after six silent reads instead of holding the port.

## Known issues
- The dongle has no update page of its own yet.

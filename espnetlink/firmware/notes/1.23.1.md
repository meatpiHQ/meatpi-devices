# ESPNetLink 1.23.1

## Before you update
- Units already on this partition layout (v1.23 (two 5 MB OTA slots, settings, storage, coredump)) update in place.
- Units coming from firmware 1.20.0 (v1.20 (one factory app slot, no OTA)) cannot update over the air: flash this release over USB with the serial flash set.

## New features
- None in this release.

## Bug fixes
- The status LED shows amber (orange) while the mobile network is still connecting. It used to drive red and green at equal levels, which the light pipe showed as a lime green that was hard to tell from the solid green of an uplink that is up.

## Known issues
- The dongle has no update page of its own yet.

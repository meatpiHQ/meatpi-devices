# WiCAN PRO 4.51.0

## New Features:
- Latest IDF v6.0.2

## Bug Fixes:
- Fixed an AutoPID issue where some vehicle profiles were returning incorrect PID values. #710

## Update Instructions
- Download the latest firmware file.
- Unzip the downloaded file.
- Open the configuration page and go to the **System** tab.
- In the **Firmware Update** section, upload the file named `wican-fw_obd_pro_vxxxp.bin`.
- Press **Update** to start the process.

## In case of a boot loop, you can perform a [factory reset ](https://meatpihq.github.io/wican-fw/factory-reset/factory-reset)
